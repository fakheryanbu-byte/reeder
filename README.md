# مُجهّز بيانات النزلاء | Guest Check-In Prep

تطبيق ويب متجاوب (Mobile-First) بالعربية والإنجليزية لقراءة وثائق النزلاء واستخراج البيانات الظاهرة عبر **Google Gemini** من خلال خادم آمن، ومراجعتها واستكمالها في الصفحة نفسها، ثم فتح **واتساب** برسالة جاهزة يرسلها المستخدم بنفسه.

## الميزات الرئيسية
- **واجهة واحدة متجاوبة (RTL / LTR)**: العربية افتراضية مع زر تبديل فوري `العربية | English` يحفظ جميع البيانات المدخلة دون ترجمة أسماء النزلاء.
- **استخدام عام ومباشر عبر واتساب**: يجهّز الرسالة ويفتح واتساب لاختيار جهة الاتصال وإرسالها فوراً (مع إمكانية ضبط رقم واتساب افتراضي اختياري عبر متغيرات البيئة).
- **قراءة الوثائق عبر الخادم فقط**: يستدعي الخادم `gemini-4-hydrogen` باستخدام `GEMINI_API_KEY` مع التحقق من نوع وحجم الصورة، والحد من معدل الطلبات، ومخرجات JSON مهيكلة (Structured Output).
- **قواعد شرطية لكل وثيقة**:
  - **الهوية الوطنية والإقامة**: إظهار وإلزام رقم النسخة.
  - **جواز السفر**: إخفاء رقم النسخة وإظهار رقم الحدود الإلزامي مع توضيح اختلافه عن رقم الجواز والتأشيرة، وخيار طلب مساعدة الاستقبال (يُرسل كـ «ناقص بيانات»).
  - **سجل الأسرة**: اختيار النزيل الرئيسي والمرافقين الفعليين فقط دون نسخ رقم صاحب السجل للآخرين.
- **الخصوصية**: لا يحتفظ التطبيق بأي نسخة من صورة الوثيقة بعد قراءة البيانات أو إرسالها (تُمسح الصورة فوراً من الذاكرة المؤقتة)، ولا تُحفظ البيانات في التخزين الدائم أو السجلات، مع زر «مسح بياناتي / Clear my data».

## الإعداد والتشغيل (Setup & Running)

### 1. متغيرات البيئة (`.env`)
انسخ ملف `.env.example` إلى `.env` واملأ القيم المطلوبة:

```bash
cp .env.example .env
```

- `GEMINI_API_KEY`: مفتاح Google Gemini API (يُستخدم على الخادم فقط).
- `RECEPTION_WHATSAPP_NUMBER` *(اختياري)*: رقم واتساب افتراضي بالصيغة الدولية بالأرقام فقط (مثال: `9665XXXXXXXX`). عند تركه فارغاً، يفتح واتساب لاختيار جهة الاتصال مباشرة.

### 2. تثبيت الحزم والتشغيل للتطوير

```bash
npm install
npm run dev
```

سيعمل الخادم والواجهة على المنفذ `3000`.

### 3. البناء والتشغيل للإنتاج

```bash
npm run build
NODE_ENV=production npm start
```

### 4. النشر على Vercel
يحتوي المشروع على دوال Serverless في مجلد `api/` وملف `vercel.json` متوافق مع Vercel. عند الرفع على Vercel:
1. افتح إعدادات المشروع في **Vercel > Settings > Environment Variables** وأضف `GEMINI_API_KEY` (ويمكنك اختيارياً إضافة `RECEPTION_WHATSAPP_NUMBER`).
2. أعد النشر (**Redeploy**) بعد حفظ المتغيرات لتعمل قراءة الوثائق.

### 5. الاختبارات وفحص الأنواع

```bash
npm run lint
npm test
```
